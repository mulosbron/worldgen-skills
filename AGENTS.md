# Procedural World Generation

When the user asks for world generation, terrain, biomes, caves, towns, or an
open world, use the `worldgen` skill. It covers the decisions to lock, the
build order, and the definition of done. Read `worldgen-pitfalls` before
writing code, and `worldgen-sites` when the world needs structures.

Working generator code in the project's own engine and language is the
deliverable. Keep notes to one short `worldgen/DECISIONS.md`.
